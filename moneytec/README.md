# Moneytec

Independent Moneytec brand concept and interactive planning website within the Akshay-vriksha repository. AkshayVriksha remains separate.

Run: `python3 -m http.server 5180 --directory moneytec/dist` from the repository root.

Content is a brand concept pending business details. Tools are browser-local illustrations. No accounts, transactions, live market data, or claimed registrations.
