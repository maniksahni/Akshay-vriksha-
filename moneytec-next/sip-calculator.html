03

The formula behind it

The calculator converts the yearly return to an equivalent monthly rate, i = (1 + r)1/12 − 1, then calculates:

Future value = P × [((1 + i)n − 1) ÷ i] × (1 + i)

Here P is the monthly SIP and n is the number of months. Some other calculators use r ÷ 12 as the monthly rate, so their answers can be slightly higher.

04

What moves the result most

  • Time: later years add more because earlier growth is also growing.
  • Amount: doubling the SIP doubles the illustrated value.
  • Return: a small change compounds over time, so also try a lower return to see a more cautious picture.

05

Frequently asked questions

How accurate is a SIP calculator?

It is only an illustration. It assumes the same return every year, while real mutual fund returns vary and can be negative over some periods. Use it to compare scenarios, not to predict an outcome.

What return should I assume?

There is no correct number. Try a few, including a cautious one, because no return is guaranteed and it depends on the scheme and market conditions.

Does this calculator include tax or fund costs?

No. The result is before tax and uses only the return you enter, so check the scheme’s expense ratio, any exit load and current tax rules.
